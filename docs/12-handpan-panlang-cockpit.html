Why ~80% Token Compression Slashes Decision Latency

        
gemini-decision-1 emits 0 output tokens (calibrated logprobs from a single forward pass), making end-to-end RTT almost purely a function of prefill token count and question criteria length.

        
Prototype 05 serialized musical context as ~310 tokens of English prose plus ~600 tokens across 6 verbose questions (~910 total prefill tokens). PanLang encodes pitch contour, harmonic function, locked motifs, organic rubato, and 3-vector steering in ~45–62 tokens, paired with a razor-tight 2-question suite (move + deg, ~95 criteria tokens).

        
Speculative Prefetching: Queries launch 1.5 beats before each bar boundary so distributions arrive before they are consumed. Any live user gesture (2D pad drag, Breath Dial turn, live keystroke, lock, or fork) immediately cancels stale calls via AbortController and re-speculates.
