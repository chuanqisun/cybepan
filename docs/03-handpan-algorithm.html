A flat Markov chain wanders without phrasing; a rigid loop grows stale. To generate infinite handpan music that always sounds intentional and grammatical, this engine couples four hierarchical stochastic processes driven by a rock-solid Web Audio lookahead clock:

1. Boltzmann Softmax Pitch-Transition Energy Function

Given previous tone-field index i, active chord tone set C, target contour direction d ∈ {-1, 0, +1}, and preferred alternating hand h* ∈ {L, R}, each candidate tone field j ∈ {0..8} is assigned an energy cost E(i, j):

E(i, j) = w_chord · 𝟙[j ∉ C]
        + w_step  · | |j - i| - 1.5 |          // favors conjunct steps & thirds, penalizes wide jumps
        + w_hand  · 𝟙[hand(j) ≠ h*]            // favors physical L↔R zigzag ergonomics
        + w_dir   · 𝟙[sign(j - i) ≠ d]         // encourages coherent phrase contour / gap-fill
        + w_rep   · 𝟙[j = i]                   // discourages stagnant immediate pitch repetition

P(j | i) = exp( -E(i, j) / τ ) / Σ_k exp( -E(i, k) / τ ),    τ = 0.16 + 2.1 · entropy_eff

2. Bjorklund Euclidean Rhythm Allocation & Motif Evolution

Structural accent slots in each bar are generated by Bjorklund's algorithm E(k, n), where n ∈ {7, 8} (supporting both 4/4 tresillo-family and 7/8 aksak meters) and k = clamp(round(2 + 4.5 · density_eff), 2, n - 1). A Motif DNA (an abstract sequence of relative scale-degree offsets + contour) is stored in episodic memory and transformed across clauses by probabilistic operators controlled by mutation:

  • Identity Recall: Exact rhythmic & contour repetition (establishes thematic recognition).
  • Melodic Inversion: Mirrors interval offsets around the clause's modal pivot.
  • Retrograde: Reverses the motif's pitch trajectory for consequent closure.
  • Stochastic Perturbation: Re-samples a subset of steps through the Boltzmann distribution.
